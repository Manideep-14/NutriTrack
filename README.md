# NutriTrack

## Project Description

NutriTrack is a Flask-based nutrition tracking application that helps users monitor daily meals, protein intake, calories, and nutrition goals.

## Features

* Add meals with protein and calorie information
* View meal dashboard
* Delete meals
* Track daily protein goal progress
* View nutrition summary
* Protein distribution pie chart
* Success message after adding meals

## Technologies Used

* Python
* Flask
* HTML
* CSS
* Chart.js

## How to Run

1. Install Flask
   pip install flask

2. Run the application
   python3 app.py

3. Open browser
   http://127.0.0.1:5050
